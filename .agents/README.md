# Dokumen Kerja AI Project

Folder ini menyimpan konteks dan progres kerja proyek untuk pengembang dan asisten AI.

## Daftar dokumen

- [TASKLIST.md](TASKLIST.md): daftar pekerjaan utama dan kriteria selesai.
- [TODO.md](TODO.md): langkah operasional untuk sesi berikutnya.
- [ISSUES.md](ISSUES.md): pencatatan bug, kendala, dan hasil penyelesaian.
- [SKILLS.md](SKILLS.md): katalog kemampuan dan referensi skill proyek.
- [REQUIREMENTS.md](REQUIREMENTS.md): tujuan, lingkup, serta kebutuhan proyek.

## Cara menggunakan

1. Baca `AGENTS.md` di root dan aturan proyek yang berlaku.
2. Baca kebutuhan, pilih task, lalu pecah pekerjaan menjadi checklist to-do.
3. Catat kendala di issues dan tautkan ID issue ke task terkait.
4. Setelah bekerja, perbarui status, hasil verifikasi, dan langkah berikutnya.

Gunakan ID `TASK-001`, `TODO-001`, `ISSUE-001`, dan `REQ-001` secara konsisten. Status task: `backlog`, `ready`, `in_progress`, `blocked`, `done`. Prioritas: P0 mendesak, P1 tinggi, P2 normal, P3 rendah.

Jangan menyimpan password, token, API key, isi `.env`, atau data pribadi di dokumen ini. Tandai informasi yang belum diketahui sebagai `Belum ditentukan`.
