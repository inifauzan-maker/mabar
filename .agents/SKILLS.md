# Katalog Skill Proyek

Dokumen ini adalah katalog kemampuan, bukan skill eksekusi. Baca `SKILL.md` dari skill yang relevan sebelum menggunakannya.

## Kemampuan yang dibutuhkan

| Area | Digunakan untuk | Bukti hasil |
| --- | --- | --- |
| Analisis kebutuhan | Merumuskan lingkup dan kriteria penerimaan | REQUIREMENTS.md dan task terkait |
| Laravel / PHP | Implementasi backend sesuai pola proyek | Perubahan kode dan verifikasi relevan |
| Database | Desain skema dan migrasi jika diperlukan | Skema, migrasi, dan rencana pemulihan |
| Frontend | UI sesuai stack yang terpasang | Hasil build dan pemeriksaan tampilan |
| Pengujian | Menguji perilaku yang berubah | Perintah dan hasil tes |
| Integrasi AI, jika diperlukan | Prompt, provider, evaluasi, dan biaya | Evaluasi pada contoh representatif |

## Skill yang disediakan Laravel Boost

Installer menyediakan `infer-conventions`, `laravel-best-practices`, `testing-best-practices`, `tailwindcss-development`, dan `deploying-to-cloud`. Kelima skill sudah terpasang dan diverifikasi pada `.agents/skills/<nama-skill>/SKILL.md`. Kendala instalasi awal telah selesai; lihat ISSUE-001.
